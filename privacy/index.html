개인정보처리방침 안내

홈페이지와 앱의 안내를 구분해서 확인해 주세요.

안내 기준일: 2026년 11월 11일

앱 개인정보처리방침은 준비 중이에요.

이 페이지는 공식 홈페이지의 현재 구성과 앱 정책 준비 상태를 안내해요. 정식 앱의 최종 개인정보처리방침은 실제 출시 기능과 데이터 처리 내용을 확인한 뒤, 출시 전에 별도로 공개할 예정이에요.

1. 이 홈페이지에서 입력받는 정보

현재 홈페이지에는 회원가입, 로그인, 문의 입력 양식이 없어요. 운영자가 방문자의 이름, 연락처, 문의 내용을 직접 입력받는 기능은 제공하지 않아요.

방문 통계·광고 도구나 외부 웹폰트를 연결하지 않았어요. 이 홈페이지 코드에는 쿠키나 브라우저 저장소에 방문 정보를 저장하는 기능이 없어요.

2. 웹 호스팅 과정의 접속 정보

이 홈페이지는 GitHub Pages를 통한 호스팅을 위해 제작되었어요. GitHub는 GitHub Pages 방문자의 IP 주소를 보안 목적으로 기록·보관한다고 안내하고 있어요. 홈페이지 운영자의 입력 양식 운영 여부와는 별개의 호스팅 처리예요.

구체적인 처리는 GitHub 개인정보처리방침과 GitHub Pages 안내에서 확인해 주세요.

3. 앱의 개인정보 안내

앱에서 처리하는 공수 기록, 프로필, 위치·건강 정보 등은 홈페이지 방문 정보와 달라요. 체험 모드와 로그인 모드의 실제 출시 범위를 확인해, 항목·목적·보관·삭제·권한 및 외부 서비스 처리를 최종 정책에 정리할 예정이에요.

이 페이지를 정식 앱의 확정 정책으로 안내하지 않아요. 앱 정책 검토 초안은 공개 홈페이지 배포 파일과 분리해 관리해요.

4. 문의와 변경 안내

홈페이지·브랜드 관련 문의는 frolymo2016@gmail.com으로 보내 주세요. 이메일 문의 시 직접 보내 주시는 이메일 주소와 문의 내용을 확인하고 답변해요. 홈페이지에는 이메일을 수집하는 입력 양식이 없어요. 앱의 최종 정책은 실제 처리 내용과 운영 정보를 확정해 별도로 공개할 예정이에요.
